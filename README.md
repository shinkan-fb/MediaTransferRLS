# Media Transfer — Windows Releases

Publiczne repozytorium gotowych wydań programu Media Transfer na Windows.

Kod źródłowy jest utrzymywany w prywatnym repozytorium. To repozytorium udostępnia wyłącznie pliki dystrybucyjne, bez źródeł Flutter/Dart.

## Instalacja
Pobierz najnowsze wydanie z zakładki **Releases**, rozpakuj `MediaTransfer-Windows.zip` do wybranego katalogu i uruchom `media_transfer.exe`. Nie uruchamiaj programu bezpośrednio z ZIP. Zachowaj wszystkie pliki w paczce.

## Aktualizacje
Program sprawdza nowe wydania po uruchomieniu. **Teraz** pobiera i instaluje aktualizację z ponownym uruchomieniem. **Podczas zamykania** pobiera aktualizację i instaluje ją przy zamknięciu, bez restartu. Aktualizacje nie ingerują w ustawienia zapisane w profilu Windows.

Każde wydanie musi zawierać `MediaTransfer-Windows.zip` oraz `SHA256SUMS.txt`.

Pierwsze wydanie nie zostało jeszcze opublikowane.
